# `data/eda/` — CUAD full-corpus exploratory analysis

**Status:** tracked (committed)

Reproducible EDA over the 510-contract CUAD corpus. Generated by
`scripts/eda/explore_cuad.py` and checked in so collaborators can read the
headline stats without re-running the script.

## Files

| Path | Description |
|---|---|
| `report.md` | Full EDA report (corpus composition, lengths, category rates, co-occurrence) |
| `findings.md` | Curated takeaways for prompt/scorer design |
| `figures/01`–`10` | PNG charts referenced by the report |

## Regenerate

```bash
python scripts/eda/explore_cuad.py
```

Requires the CUAD JSON corpus (from Braintrust sync or
[`data/cuad_pdfs/CUAD_v1.json`](../cuad_pdfs/README.md)).

## Headline stats (from `report.md`)

- 510 contracts, 41 QA categories, median ~33k chars/doc (max 338k)
- 17.1% of docs exceed the 90k chunked-extraction window
- `key_obligations` GT scope: mean 16 spans/doc (partial-GT scoring surface)
